# 日経記事かんたん解説アプリ

日経電子版などから手動でコピーした記事タイトル・本文を貼り付けると、Claude (Anthropic API) が
3行要約・やさしい解説・背景・賛否論点・企業/生活への影響・30秒版などを生成して表示する、
個人利用向けのローカルStreamlitアプリです。

## セットアップ

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."   # またはアプリ起動後にサイドバーで入力
streamlit run app.py
```

ブラウザで `http://localhost:8501` が開きます。

## 使い方

1. 記事タイトルと本文（日経電子版からコピー）を貼り付ける
2. 必要に応じて「特に知りたいこと」「追加指示」を入力
3. サイドバーで難易度・出力の長さ・経営者目線の有無を設定
4. 「解説する」を押すと解説が表示される
5. 生成後は記事についての追加質問も可能

## 注意

- 記事本文はコピー＆ペーストで手動投入する方式です（自動スクレイピングは行いません）。
- 入力した記事本文・APIキーはこのローカルアプリとAnthropic APIの通信にのみ使用されます。
