# 日経記事かんたん解説アプリ

日経電子版などから手動でコピーした記事タイトル・本文を貼り付けると、Claude (Anthropic API) が
3行要約・やさしい解説・背景・賛否論点・企業/生活への影響・30秒版などを生成して表示する、
個人利用向けのローカルStreamlitアプリです。

## セットアップ

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."   # またはアプリ起動後にサイドバーで入力
streamlit run app.py
```

ブラウザで `http://localhost:8501` が開きます。

## デスクトップショートカット（Windows）

1. このリポジトリをPCの任意の場所にクローン（または保存）する
   例: `git clone <repos-url> C:\Users\<ユーザー名>\nikkei-app`
2. Python未インストールの場合は事前にインストールしておく（インストール時に「Add python.exe to PATH」にチェック）
3. APIキーを毎回入力せず使いたい場合は、コマンドプロンプトで以下を実行して環境変数を登録しておく（1回だけでOK、実行後は新しいウィンドウから有効）
   ```bat
   setx ANTHROPIC_API_KEY "sk-ant-..."
   ```
4. エクスプローラーで `run_app.bat` を右クリック →「送る」→「デスクトップ (ショートカットを作成)」を選ぶ
5. デスクトップにできたショートカットをダブルクリックすると、初回は仮想環境の作成と依存パッケージのインストールが自動で行われ、ブラウザでアプリが開く（2回目以降は起動のみで数秒で立ち上がる）

## 使い方

1. 記事本文を入力する。方法は3通り
   - 日経電子版から本文をコピー＆ペースト
   - 記事のスクリーンショット画像ファイルをアップロードして「画像から読み込む」
   - スクリーンショットを撮った直後に「📋 クリップボードから貼り付け」ボタンを押して直接読み込む（保存不要。Windowsなら `Win+Shift+S` で撮影 → そのままボタンを押すだけ）
   - 記事タイトル欄は空欄のままでも構わない。空欄の場合は本文の中から見出しをClaudeが自動判別する（本文にタイトルが含まれている前提の運用に対応）
2. 必要に応じて「特に知りたいこと」「追加指示」を入力
3. サイドバーで難易度・出力の長さ・経営者目線の有無を設定
4. 「解説する」を押すと解説が表示される
5. 生成後は記事についての追加質問も可能
6. 生成した解説は自動でローカルに保存され、サイドバーの「📚 保存済みを検索」からタイトル・本文・解説内容に含まれるキーワードで検索できる
7. 次の記事を調べたいときは「🗑 すべてクリアして次の記事へ」を押すと、タイトル・本文・画像・解説結果・質問履歴が一括で消えて新しい記事を入力できる状態に戻る（保存済みの解説は消えない）

## 見出しピックアップ

日経電子版のトップページや一覧画面から見出しの並びをまとめてコピーし、サイドバーの
「🔍 見出しピックアップ」に貼り付けると、関心テーマに関連する見出しだけをClaudeが抜き出して
理由付きで表示します（記事本文の自動取得・自動ログインでのページ巡回は行いません。あくまで
手動でコピーしたテキストを解析するだけです）。

- 「🔑 登録キーワード」でよく調べたいキーワード（例: ニチロ、ディーゼルエンジン用フィルタ、社会保険料 など）を登録しておくと、
  「関心テーマ・キーワード」欄に自動で反映されます。都度キーワードを入力し直す必要はありません。
- 登録キーワードは `history.db` に保存され、次回起動時も引き継がれます。

## 保存データについて

- 解説結果・登録キーワードは `history.db`（SQLite、アプリと同じフォルダ内）に自動保存されます。
- 「📚 保存済みを検索」ページでキーワード検索（部分一致）ができ、各結果を展開して解説内容を確認・削除できます。
- `history.db` はこのPC上にのみ保存され、Gitの管理対象外（`.gitignore`）です。

## 注意

- 記事本文はコピー＆ペースト、または手元で撮影・保存したスクリーンショット画像のアップロードで手動投入する方式です（自動スクレイピングは行いません）。
- 見出しピックアップも同様に、日経のページから手動でコピーした見出しテキストを貼り付けて使う方式です。自動ログインしてページを巡回するような機能は意図的に実装していません（利用規約上のリスクを避けるため）。
- 画像から読み込む場合、読み取り精度は画像の解像度・鮮明さに左右されます。読み込み後は必ずタイトル・本文を確認し、必要に応じて修正してから「解説する」を押してください。
- 入力した記事本文・画像・見出しテキスト・APIキーはこのローカルアプリとAnthropic APIの通信にのみ使用されます。
